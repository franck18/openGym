# Références de l’évolution FrayFit

Recherche du 6 novembre 2026, GitHub et documentation primaire.

- [wger](https://github.com/wger-project/wger) et son [manuel des routines](https://github.com/wger-project/docs/blob/master/docs/manual/routines.rst) : organisation des routines et progression, code annoncé AGPL-3.0-or-later. Retenu : aperçu du planning avant ajout et cohérence de la prescription affichée.
- [Workout.cool](https://github.com/Snouzy/workout-cool), README : programmes et recherche d’exercices, code annoncé MIT. Retenu : choix clair, filtres de fréquence et matériel, aperçu détaillé avant application.
- [Ryot](https://github.com/IgnisDa/ryot), README : séances et mesures avec graphiques, code annoncé GPLv3. Retenu : bilan lisible issu de l’historique réel.

Aucun code, logo, média ou jeu de données provenant de ces trois projets n’a été intégré. Les composants sont écrits pour FrayFit et réutilisent buildStarterPlan, loadStarterPlan, workoutDay, workoutDuration, doneUnits, calendarSheet et workoutDetailSheet. Aucun service externe n’est requis.

Le catalogue et les animations existants restent inchangés avec leurs licences. Les statistiques relisent les séances enregistrées. L’aperçu de programme respecte les routines déjà personnalisées.
